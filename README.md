# GST Billing Application
# Student: Manav (22IT005)

A Flutter application for managing GST billing and inventory.

## Features

- Product management with GST rates
- Easy product search by name or barcode
- Shopping cart functionality
- GST calculation
- Bill generation
- Clean and intuitive UI

## Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio / VS Code

### Installation

1. Clone the repository
```bash
git clone https://github.com/22it005manav/gst_billing.git
```

2. Install dependencies
```bash
flutter pub get
```

3. Run the app
```bash
flutter run
```

## Built With

- Flutter - The UI framework used
- Provider - State management
- SQLite - Local database
